# Project Acceleracers Trainer — Recode (Русский)

Внутренняя DLL-читерская программа (тренер) для **Project Acceleracers** (UE4 4.27),
написанная на C++ с полностью собственным оверлеем на ImGui. Она перехватывает рендерер
игры, выполняет игровые функции в игровом потоке и включает **категорию тем**, которая
позволяет переключать весь внешний вид ImGui между UI-пакетами из локальной папки
`imGUIS/`.

> Инструмент для одиночной игры. Образовательный проект. Никаких мультиплеерных функций,
> никакого обхода античита, ничего упакованного или скрытого — исходный код компилируется
> как есть.

---

## Возможности

### Игрок
- Бесконечный Nitrox (восполняется каждый кадр)
- Бесконечные Jump Jets (заряды Accelecharger пополнены, перезарядка сброшена)
- Идеальная управляемость (максимальное сцепление шин, регулируемый ползунок grip)
- Заряды Accelecharger (регулируемый счётчик)
- Усиление HP двигателя (снимает `EngineBlown`)
- Noclip (WASD + Space/Ctrl, регулируемая скорость)
- Режим бога (иммунитет к молниям Storm, шипам и порывам ветра)
- Hydro Tires: без замедления в воде / Spike Tires: без остановки в песке

### Прогресс
- Открыть все автомобили (каждая запись `ECarList` 0–112)
- Открыть все AcceleChargers (каждая запись `EAccelechargers` 0–16)
- Установить все рекорды реалмов (вызов `SaveGameTime` для всех 47 реалмов)
- Сохранить прогресс через собственный `Save_Game` игры

### Мир
- Определение текущего реалма в реальном времени (имя портала `LevelOut` + таблица дампа)
- Завершить текущий реалм (ставит машину в выходной портал)
- Список реалмов с координатами и статусом
- Диагностика движка: счётчики миров/уровней/акторов/порталов, проверка ID игрового потока

### Категория тем
Четвёртая вкладка, **THEME**, мгновенно пересобирает стиль ImGui из палитр, извлечённых
из UI-пакетов в `imGUIS/`:

| Тема | Пакет-источник | Вид |
|---|---|---|
| Default | оригинальный тренер | тёмный серо-синий, оранжевый акцент |
| Neverlose | `neverlose-last` (`gui.hpp`, `neverlose_menu.cpp`) | тёмно-синие карточки, синий акцент |
| Skeet | `skeet.cc-master` (производная — пакет содержит стандартный ImGui) | почти чёрный, зелёный акцент |
| Onetap | `onetap ui remake` (`ui/core/ui_theme.h`) | графит, красный акцент |
| Fatal UI | `project-139` (`FatalUITest/menu/Menu.cpp`) | графит, сине-фиолетовый акцент |

## Аудит безопасности imGUIS

Перед использованием любого пакета все исходные файлы во всех пяти архивах были
проверены на сетевые вызовы, запуск процессов, закрепление в системе и обфусцированные
полезные нагрузки.

| Пакет | Вердикт | Примечания |
|---|---|---|
| `neverlose-last (1).rar` | **чисто** | стандартный форк ImGui + собственный код отрисовки меню |
| `neverlose-last-main.zip` | **чисто**, 1 висячая ссылка | `examples/example_win32_directx11/build_win32.bat` вызывает `..\..\run_menu.ps1`, которого нет нигде в архиве. Скрипт отсутствует (удалён или никогда не поставлялся), и всё дерево `examples/` тренером не используется. |
| `skeet.cc-master.zip` | **чисто** | немодифицированный стандартный ImGui, кода тем нет |
| `onetap ui remake.zip` | **чисто** | ImGui + ремейк виджетов, чистый код отрисовки |
| `project-139.rar` | **чисто** | ImGui + библиотека отрисовки FatalWidgets |

Сетевых сокетов, загрузок, записей в реестр, запланированных задач, инъекций процессов
или закодированных блобов в компилируемом коде не найдено. Тренер использует только
цветовые палитры и константы стилей — код самих пакетов в DLL не линкуется.

## Сборка

Требования: Visual Studio 2022 (или 2026) с рабочей нагрузкой «Разработка классических
приложений на C++», Windows 10/11 x64.

1. Откройте `AcceleracersTrainer.sln`.
2. Выберите **Release / x64**.
3. Соберите. Результат: `bin\Release\AcceleracersTrainer.dll`.

Командная строка:

```bat
msbuild AcceleracersTrainer.vcxproj /p:Configuration=Release /p:Platform=x64
```

ImGui (бэкенды DX11 + Win32) и MinHook включены в `third_party/` — без пакетных
менеджеров, без внешних загрузок, одна команда сборки.

## Установка и использование

1. Запустите **Project Acceleracers** (лучше всего в оконном или безрамочном режиме).
2. Инжектируйте `AcceleracersTrainer.dll` любым стандартным DLL-инжектором.
3. Нажмите **INSERT**, чтобы открыть/закрыть меню.
4. Выберите вид во вкладке **THEME**; включайте функции в остальных вкладках.

Функции выполняются в игровом потоке (перехват через `UObject::ProcessEvent`) и
отклоняются, если тренер вдруг захватит не тот поток — см. показания `GT`/`Render`
во вкладке WORLD.

## Структура проекта

```
AcceleracersTrainer/
├── AcceleracersTrainer.sln
├── AcceleracersTrainer.vcxproj
├── src/
│   ├── dllmain.cpp      # точка входа: поток загрузки
│   ├── hooks.cpp/.hpp   # хуки Present/Resize/ProcessEvent, D3D11-оверлей
│   ├── features.cpp/.hpp# движок функций + отложенные действия
│   ├── menu.cpp/.hpp    # собственное ImGui-меню, 4 вкладки
│   ├── themes.cpp/.hpp  # система палитр (вкладка THEME)
│   ├── realms.hpp       # таблица порталов реалмов (47 реалмов)
│   ├── game.hpp         # игровые смещения и вспомогательные функции
│   ├── ue.hpp           # минимальное ядро UE4: GNames, GWorld, FName, ProcessEvent
│   └── gamethread.hpp   # захват игрового потока
└── third_party/
    ├── imgui/           # Dear ImGui + бэкенды DX11/Win32
    └── minhook/         # MinHook
```
